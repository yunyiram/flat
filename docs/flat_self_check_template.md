## 1. 적용 범위

- 모든 응답 (코드탭 / 기획탭 / 외부 채팅 / 코워크 탭).

## 2. 항목 수 = 복잡도 함수 (9-16개)

| 복잡도 | 항목 수 | 적용 |
|--------|---------|------|
| 단순 진행 (도구 1-2회, 의사결정 없음) | **9** | A1+A2+A3, B (해당 1-2), C (해당 1), D1-D4, E1 |

## 4. 응답에 명시 형식

```
**[그룹.번호] [항목 짧은 이름]**: [✅ / ⚠️ / N/A] [한 줄 근거 또는 사유]
```

예시 (매트릭스 작성 응답에서 인용):
```
**A1. 추측 단정 금지**: ✅ write_file 작동도 사후 read 검증 후 "검증 완료" 명시
**D3. 실제 호출 검증**: ✅ write_file → read 사후 검증 + edit_file dryRun + 적용
**E3. 신규 vs 변형 판정**: ✅ MCP timeout = 사고 (s) 동일 → 변형 → 별도 RCA 안 만듦
```

**N/A 표시 시**: "해당 없음" 만으로 부족. 사유 명시 (예: "push back 없음, A5 N/A").

## 5. 변질 위험 + 완화 메커니즘 (양식 자체 내장)

### 5.1 도장 패턴 회피 (사고 f)
- D5 매번 의무. ✅ 표시 후 본문에 추측/모순 있으면 즉시 자가 정정
- ✅ = 점검 결과 명시. 형식 충족 ≠ 점검 통과

### 5.2 형식적 채우기 회피
- 9-16개 = 복잡도 함수. 단순 응답에 16개 = 변질 신호 (사고 (n) 변형 = 비용 합리화의 반대 = 의무 채우기 합리화)
- 항목 N/A 시 사유 명시 의무

### 5.3 신규 사고 인지 약화 회피 (표준화 위험)
- E3 매번. 본 응답에서 새 패턴 발생 가능성 능동 점검
- 규칙 9 strict/lenient 비대칭 적용 — 의심 시 새 패턴
- 양식 = 알려진 패턴 정리. **알려지지 않은 패턴은 양식 밖**. E3가 그 경계 보존

### 5.4 양식 자체 outdated 위험
- 원칙 추가/수정 시 본 양식 동기화 의무
- 매트릭스 § 6 패턴 답습 — § 8 마지막 검증 일자 갱신
